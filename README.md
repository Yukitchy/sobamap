# Sobamap

そば・うどんの個人記録マップ。行った店のレポと、行きたい店のリストを一枚の地図で見る。
Eatmap（akiba-where-to-eat）の基本設計（マップ＋リスト、チップ絞り込み、店舗カード）を踏襲し、配色と細部をそば専用にしたもの。

## 構成

- `index.html` — アプリ本体（CSS/JS 内包）
- `data.json` — 店データ（正本）。画面はこれを読んで描画する

## ローカルで見る

`file://` では `data.json` を読み込めないブラウザがあるため、簡易サーバ経由で開く:

```sh
cd sobamap
python3 -m http.server 8799
# → http://localhost:8799/
```

GitHub Pages に置けばそのまま動く。

## 店の追加・編集

`data.json` の `shops` にオブジェクトを1件追加するだけ。

| フィールド | 値 |
|---|---|
| `id` | 半角英数とハイフン（一意） |
| `name` | 店名 |
| `type` | `"soba"` / `"udon"` |
| `style` | `"standing"`（立ち食い）/ `"seated"`（着席）/ 不明なら `null`（チップを出さない） |
| `status` | `"visited"`（訪問済み）/ `"wishlist"`（行きたい） |
| `area` | エリア名（例：神保町） |
| `address` | 住所 |
| `lat` / `lng` | 緯度・経度（住所から国土地理院の住所検索などで確認） |
| `visit_date` | 訪問済みのみ（例：`2026年11月上旬`） |
| `dish` | 食べた一杯 |
| `rating` | 星 1–5 / 未評価は `null` |
| `memo` | 訪問済み＝レポメモ、行きたい＝気になる理由 |
| `photo` | 写真のパス（なければ `""`） |

行きたい店へ行ったら `status` を `"visited"` に変え、`visit_date` / `dish` / `rating` / `memo` を埋める。

## 絞り込みチップ

- そば / うどん（種別）、立ち食い / 着席（形式）はタップで ON/OFF、組み合わせ可
- 同じ軸の中は OR、軸と軸の間は AND（例：そば＋立ち食い＝立ち食いのそば屋だけ）
- 「すべて」で解除

## 地図

Eatmap と同じスケッチマップ方式。ピンの位置は `lat`/`lng` から自動で配置され、色は 訪問済み＝抹茶色、行きたい＝白抜き＋茶色の枠。番号は下のリストと共通。
